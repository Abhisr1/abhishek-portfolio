# ABHISHEK — THE SERIES

A cinematic, streaming-inspired portfolio for Abhishek S R, Mechanical Design Engineer | Design Engineer.

## Run locally

Requires Node.js 18+.

```bash
npm install
npm run dev
```

Production build: `npm run build`; the static site is generated in `dist/`.

## Updating content

Portfolio content is centralized in `src/data/portfolio.ts`. Update the profile, education, experience, projects, skills, awards, and links there. Replace the public resume PDF in `public/assets/` only with a version that has been approved for public sharing and does not expose personal phone numbers or confidential information.

## Confidentiality note

Project descriptions are intentionally sanitized. Do not publish proprietary customer drawings, dimensions, part numbers, BOMs, CAD files, internal documents, or unapproved project imagery. Confirm employer/customer authorization before publishing any project-specific details.

## Stack

React 18, TypeScript, Vite, Tailwind CSS 4, Framer Motion, and Lenis.
